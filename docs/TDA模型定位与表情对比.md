# TDA MTrace 的定位与表情对比

[返回 MMD 研究](../mmd表情调查/README.md) · [表情参考主表](../mmd表情调查/MMD表情参考.md)

核验日期：2026-11-01。问题是：TDA MTrace 被用作动画制作参考，是否意味着它带有比普通 TDA 更丰富的面部控制？

处理状态：已按用户要求从活跃对照列表移除。原始包、渲染和模型注册清单保留在本机 `IGNORE/`；此文仅保留用途核验记录，不将该模型计入主表。

## 结论

对本次取得的文件，**TDA MTrace v1.14 是动作描摹辅助模型，不能据“有动画作者使用”推导出“具有独立、更丰富的表情基底”**。

它可以用于表情、口型和视线动画的制作参照，但模型里的 morph 控制集合与动画作者后来制作的 VMD 不是同一份东西。当前证据支持“存在实际制作案例”，不构成“社区统一表情标准”的证明。

## 本地源 PMX 的直接对比

读取两份 PMX 的完整 morph 清单，而非只看已渲染图片。原始模型和详细检查 JSON 仅保存在本机 `IGNORE/`。

| 指标 | TDA V4X Ver1.00 | TDA MTrace v1.14 |
| --- | ---: | ---: |
| 源 PMX 顶点数 | 25,554 | 24,418 |
| 源 PMX 骨骼数 | 239 | 193 |
| 全部 morph | 69 | 64 |
| Vertex morph | 63 | 61 |
| Material morph | 6 | 3 |
| 眉、眼、口分类的 morph | 56 | 53 |

- 两份文件有 **58 个完全同名的 morph**。
- MTrace 的 **53 个眉/眼/口分类名称全部出现在 V4X 的 56 项中**；该分类下没有 MTrace 独有名称。
- V4X 独有的眉/眼/口分类名称是 `ハイライト消`、`ハンサム`、`映り込み消`。
- MTrace 独有的 6 个名称是 `C警告Off`、`G警告Off`、`スパッツOn`、`ツインテon`、`腰相対on`、`足接地On`，属于操作辅助、衣发等项目，不是新增的眉眼口形态名称。

分类取自 PMX 的 eyebrow / eye / mouth 面板，名称采用完全同名比较。两份模型的基模、顶点拓扑不同；**名称重合不能证明顶点形变逐点相同**，本记录没有作这种断言。这也是两个具体文件之间的比较，不能代表所有 TDA 派生版本。

### 渲染口径

历史参考表中的 TDA V4X 列最初按实际网格 shape key 渲染了 63 项，未单独渲染源 PMX 的 6 个材质 morph；MTrace 使用新版 mmd_tools 绑定流程，渲染了全部 64 个 morph。因此不能把表格里的“63 vs 64”理解成“新版模型多了一个面部控制”。

本次比对是对源 PMX 的完整清单作比较。历史列的形态键覆盖与完整 PMX morph 覆盖须分开评价。

### 模型包原文

解压后的 `readme.txt` 明确写明此模型以 motion trace 为目的。更新记录主要涉及辅助骨骼、显示分组、足接地指示/警告、裙装/发型和版本适配等。v1.14 更新说明涉及 `スパッツOn`。

模型与许可原文在本机保留，不复制到公开研究资料中。

### 可核对的一手公开来源

- [suwaviola：v1.14 更新公告](https://www.youtube.com/watch?v=Aa1J1Pw0MBw)：作者将其称为 motion trace model，本次公告介绍 `スパッツOn`。
- [NatsumiSan：SISTAR - SHAKE IT 制作中记录](https://www.patreon.com/natsumisan/posts/mmd-sistar-shake-32529165)：作者明确说明手工 motion trace，并列出使用该模型 v1.04。

以上是具体创作者的使用实例，不能直接量化整个社区的采用率。此前网页对话的原文未提供，本记录不判断其完整上下文；若其中把“制作参照”解释为“面部控制明显更丰富”，该解释与本次文件检查不符。

## 移除决定

该候选可用于验证 TDA 既有控制的命名兼容性，但不应当作一套独立的、更全面的表情体系来增加样本多样性，因此已从活跃模型列表中移除。

若研究的是动画作者如何得到丰富表演，还需查看其实际使用的 VMD 和组合权重/时间变化；单独渲染每个 morph 的值为 1，只能展示模型提供的单项控制。
