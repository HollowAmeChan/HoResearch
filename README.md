## 目录约定

```text
HoResearch/
├── README.md                  # 全库导航
├── .gitignore                 # 缓存、本地工程与运行日志的忽略规则
├── .gitattributes             # 文本换行与二进制文件规则
├── IGNORE/                    # 本机模型、贴图与工程，不进入 Git
├── docs/                      # 面向研究者的操作流程
├── skills/                    # 可复用的 Codex skill 和执行脚本
└── mmd表情调查/
    ├── README.md              # 研究范围、资料导航、复现方法
    ├── MMD表情参考.md          # 按 lil 完整统计频率降序排列的跨模型参考表
    ├── 模型明细/              # 各模型全部实际形态键
    ├── images/                # 正式渲染结果与总览
    ├── 附录/                  # 外部来源、原始统计与预设快照
    ├── scripts/               # 检查、渲染、整理脚本
    ├── 质检/                  # 额外的抽样检查图片
    └── *.json / *.csv         # 原始清单、名称映射与核验记录
```

各主题可以按实际需要使用不同目录结构，不必创建没有内容的占位文件夹。

## 记录方式

- 写清研究问题、软件与版本、输入来源、实验条件，以及尚未验证的判断。
- 保留可审查的原始数据、来源快照和复现脚本，让结论能回溯到证据。
- 文档导航和图片引用使用相对路径，移动目录或在 GitHub 浏览时仍可使用。
- 将已验证的观察与候选解释分开记录；补充实验时保留必要的条件差异。
- 涉及第三方资料时，在对应主题内保留作者、原始链接和引用说明。

## 版本管理范围

正常提交 Markdown、正式图片、CSV / JSON 数据、来源快照、实验脚本和必要的质检结果。

`.gitignore` 默认排除 Python 缓存与虚拟环境、依赖目录、运行日志、编辑器本地配置、`.env` 本机配置，以及 Blender 工程和备份。临时 Unity 工程的自动生成目录也会忽略。需要保留的日志节选应整理为主题内的 `.txt` 或 Markdown 记录。

原始模型包、原始贴图、打包 Blender 工程和本机配置统一放在根目录 `IGNORE/`；该目录整体忽略。各主题的 `_local/` 或 `.local/` 也可存放非模型的临时资料。正式参考图片不会被忽略。
